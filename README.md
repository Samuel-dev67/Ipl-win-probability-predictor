# 🏏 IPL Win Probability Predictor

A Machine Learning project that predicts the probability of a team winning an Indian Premier League (IPL) cricket match based on match conditions and historical data.

## 📌 Overview

The **IPL Win Probability Predictor** is a Python-based machine learning application designed to estimate the likelihood of a team winning an IPL match. It uses match-related information to generate win probability predictions, demonstrating how data science and machine learning can be applied to cricket analytics.

## ✨ Features

* 🏏 Predicts IPL match win probabilities.
* 📊 Uses match-related data to generate predictions.
* 🤖 Applies machine learning techniques to cricket analytics.
* 🐍 Built using Python and its data science ecosystem.
* 📓 Includes a Jupyter Notebook for exploration and analysis.

## 🛠️ Technologies Used

* **Python** — Core programming language
* **Pandas** — Data manipulation and analysis
* **NumPy** — Numerical computations
* **Scikit-learn** — Machine learning
* **Jupyter Notebook** — Interactive data analysis

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Samuel-dev67/Ipl-win-probability-predictor.git
```

### 2. Navigate to the project directory

```bash
cd Ipl-win-probability-predictor
```

### 3. Create a virtual environment (recommended)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install the dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
python app.py
```

Follow any instructions displayed in the terminal to use the application.
